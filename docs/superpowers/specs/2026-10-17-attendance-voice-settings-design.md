# 中文考勤语音设置

用户要求直接在 HRMS 操作：逐人编辑日语假名、选择音色、试听，满意后生成并发布。延续全部在职员工、只读姓氏，固定签到“姓氏さん、おはようございます。”、签退“姓氏さん、お疲れさまでした。”、GPU优先预生成与设备接口v1。

## 产品

- 入口 `/app/attendance-voice-settings`，中文界面，HR Manager 和 System Manager 可用。使用 Frappe Desk Page，不修改当前正在开发的 PWA、员工资料或 HR 工作区。
- 每人独立读音，全员统一音色/语速。空读音使用员工姓氏（优先员工 last_name，否则推断常见中文姓氏）；输入姓氏假名可纠正自动日语读音；页面仍显示完整姓名。员工姓名本身不修改。
- 草稿保存后仍使用当前已发布声音；预览按钮使用当前输入，分别试听签到或签退，不发布。
- 支持 Nemo 通用声音与普通 VOICEVOX 角色及风格；角色名保留原名，操作及常见风格用中文。展示声音来源署名。
- “生成全员语音”后台执行，有进度/错误；成功只得到待发布资源。“发布到签到牌”是单独操作；草稿或员工资料变化后必须重新生成。
- 正式 manifest 只在全量音频校验成功时原子替换；失败、预览、未保存修改均不破坏旧音频。设备和原 PWA 协议不变。
- 所有音频继续 mono / PCM16 / 16kHz / 最长5秒；出错保留编辑内容并给出中文反馈。

## 实现取舍

- 设置、待发布状态、预览文件在站点私有目录持久化；以文件锁保护写入和版本检查，不新增员工字段或业务 DocType。
- 所有管理 API 校验后台角色，写操作 POST+现有会话CSRF；预览下载也需要后台角色。网页不接触地点密钥、Docker socket 或任意合成地址。
- 语音引擎固定为 `nemo` / `voicevox` 两项服务，GPU优先。请求写入短期引擎租用文件；宿主机小型 systemd 用户服务读取文件，按固定 Compose 配置启动引擎，空闲60秒关闭。宿主服务没有网络端口，也不接受任意命令。
- 页面只在用户载入音色或试听/生成时租用引擎；初始载入只读设置与现有发布状态。页面与发布状态相互独立。
- 生成使用当前站点 default 队列（现有 worker），超时600秒；只允许一个生成任务，保留原发布内容。按员工快照和草稿版本验证发布资格。
- 前端使用现有 Frappe 字体、颜色、按钮和页面导航；两列配置/试听卡片、员工搜索及读音表、清楚的生成/发布状态，窄屏转为单列。

## 验收

权限拒绝普通员工；假名保存重开仍在；改读音后试听确实说新读音；可选择普通VOICEVOX角色；试听不改变当前manifest；生成成功后仍需发布；发布后设备获取新音频；失败与过时任务不覆盖当前发布；单人姓名含HTML字符不会注入页面；GPU实测和空闲释放；375px和桌面浏览器检查。
