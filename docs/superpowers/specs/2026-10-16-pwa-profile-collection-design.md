# PWA 员工资料收集

用户已完成温刚试用确认，并于 2026-10-16 授权向所有在职员工开放。

- 所有账号已启用且绑定 Active 员工档案的员工可用；仅填写本人资料。
- `pwa_profile_collection_enabled` 为全员开关；关闭时使用 `pwa_profile_collection_users` 试用名单。读取和保存均核验账号有效性、本人归属及 Active 状态。
- 首页和个人页提供「完善个人资料」入口；不符合开放条件的账号直接访问页面或接口也不能读取／提交。
- 页面沿用现有 PWA 米白、白卡片、深色文字设计，绿色用于提示和提交成功。
- 姓名和员工编号只读；手机号、现住址、联系邮箱必填；微信号选填，不按国籍限制。
- 预填现有资料。邮箱沿用总表优先级：公司邮箱、个人邮箱、登录账号邮箱。修改联系邮箱只写员工联系字段，不修改登录账号。
- 提交直接更新当前登录用户绑定的 Employee，成功页面显示摘要，提供返回首页与再次修改入口。
- API 只接收七个联系字段及 modified，不接收目标员工编号、账号、状态等任意字段；保留格式、必填和并发版本校验。
- Employee 原有通用写权限不变。仅受限接口可以代员工保存自己的七项资料。
- HR 总表仍读取同一份 Employee 资料，不复制、不新增员工、不增加审批环节。
- 不发通知，不增加强制弹窗、截止日期或打卡限制。
- 在独立测试站点验证正常提交、越权、名单撤销、版本冲突和总表同步；不代温刚填写真实资料。

补充：PWA 新增紧急联系人姓名、亲属、紧急联系电话，三项必填，复用 Employee.person_to_be_contacted、relation、emergency_phone_number。HR 总表、导出及快速编辑同步支持。已按最新授权向全体在职员工开放，不代填真实紧急联系人资料。
