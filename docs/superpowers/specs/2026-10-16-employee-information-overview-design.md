# 员工信息总表

用户已在聊天中确认本方案并授权实现。

- 使用对象：HR User、HR Manager、System Manager 和 Administrator。
- 默认筛选在职员工，清空状态可列出权限范围内的全部员工，包括离职、停用、没有登录账号和资料不完整的员工。
- 展示员工编号、姓名、部门、状态、手机号、微信号、现住址、邮箱、入职日期。
- 姓名和编号固定在左侧；姓名可打开原有员工档案，修改后刷新总表即可更新。
- 微信号为所有员工可填写的可选文本字段，不关联国籍，不计入资料缺失。
- 支持姓名、编号、电话、微信号搜索，支持公司、部门、状态和缺失电话／住址筛选。
- 手机号、微信号、完整地址可复制，长地址可展开查看。
- 支持导出全部筛选结果为 Excel，保留电话、编号和微信号的文本格式。
- 报表入口、查询和导出都遵守 HR 角色及既有员工数据权限。
- 复用 Employee 档案，不创建第二份人员资料。

实现选择：采用现有后台 Script Report，在 HR Setup 工作区增加入口；复用后台导出和档案编辑能力。

2026-10-16 用户调整：默认筛选在职；移除支店列与筛选；邮箱前移，并补充关联登录账号邮箱作为后备来源。

快捷编辑：姓名旁为有 Employee 修改权限的管理员／HR 提供编辑按钮；可改电话、微信、住址及公司／个人邮箱。登录账号邮箱只读。使用原生 Employee 读取和保存，保留权限、必填校验及并发版本检查，成功后刷新报表。
